# Mosaic — interactive tile flip

Author: Jeffrey Schnaus

Vote on reflective prompts; each vote flips a mosaic tile and reveals a piece of a second picture. As you progress, remaining front tiles dissolve until the new artwork is complete. Artwork by Jeffrey Schnaus.
